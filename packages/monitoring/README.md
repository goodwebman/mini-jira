# @gwmt/monitoring

Переносимое ядро мониторинга для Sentry SDK v11: безопасная конфигурация,
очистка событий, фильтрация ожидаемых ошибок и небольшой SDK port.
Runtime SDK передаётся через `createMonitoring({ sdk, ... })`.

[Подключение бесплатно, перенос и проверки](../../docs/sentry.md).

Сборка: `npm run build -w @gwmt/monitoring`.
Тесты: `npm run test -w @gwmt/monitoring`.
