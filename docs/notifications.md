# Уведомления и упоминания

| Событие                                                         | Получатели                                                           |
| --------------------------------------------------------------- | -------------------------------------------------------------------- |
| Добавление на доску, изменение роли, удаление с доски           | Пользователь, которого изменили                                      |
| Назначение или снятие роли в задаче                             | Новый и предыдущий участники                                         |
| Изменение названия, описания, приоритета, оценки или участников | Создатель и участники задачи                                         |
| Изменение статуса, завершение и повторное открытие              | Создатель и текущие участники задачи                                 |
| Возврат из ревью в работу/очередь                               | Те же получатели; отдельное уведомление о непрохождении ревью        |
| Возврат из тестирования в работу/ревью/очередь                  | Те же получатели; отдельное уведомление о непрохождении тестирования |
| Пауза, продолжение, запрет на взятие задачи и его снятие        | Создатель и участники задачи                                         |
| Добавление или удаление связи                                   | Создатели и участники обеих задач, каждый в контексте своей задачи   |
| Комментарий                                                     | Создатель и участники задачи                                         |
| Ответ на комментарий                                            | Дополнительно автор исходного комментария                            |
| @упоминание                                                     | Дополнительно выбранный участник доски, включая гостей               |

Участники задачи — автор, ревьювер, тестировщик и дизайнер. Собственные действия не уведомляют пользователя. Для одного изменения создаётся не более одного уведомления на получателя: упоминание приоритетнее ответа, ответ — обычного комментария. Повторные команды без изменения состояния не создают уведомлений. Удалённые с доски пользователи не получают дальнейших уведомлений о её задачах.

Запись изменения и уведомлений выполняется в одной транзакции. При ошибке сохранения уведомления откатывается и изменение. Текст содержит инициатора, ключ и название задачи. Из уведомления можно перейти к задаче или конкретному комментарию. Уведомление об удалении с доски не предлагает переход на неё.

## @упоминания

В комментарии и ответе введите `@`, найдите участника по имени или email и выберите его мышью либо стрелками и Enter. Escape закрывает выбор. Обычный текст `@Имя` без выбора пользователя остаётся текстом.

Упоминания передаются в `POST /tasks/{key}/comments` как необязательный массив `mentions`: `{ userId, start, end }`. Диапазоны отсчитываются от начала отправленного текста в единицах UTF-16, конец не включён. Текст диапазона равен `@` и имени выбранного пользователя. Сервер проверяет границы, отсутствие пересечений, имя и членство пользователя именно в доске задачи. Несколько одинаковых имён различаются по ID. Упоминания сохраняются вместе с комментарием; переименование пользователя не переписывает историю.

## Структура и запуск

На фронте данные, форматирование и редактирование упоминаний находятся в `entities/comment`, уведомления — в `entities/notification`, ввод и отправка — в `features/comment/add-comment`, просмотр и чтение уведомлений — в `features/notification/inbox`. `widgets/task-detail` собирает комментарии и ответы. Между слоями используются публичные API слайсов.

На бэке модуль `notifications` формирует получателей и сохраняет события. Модули `tasks`, `comments` и `boards` вызывают его внутри своих транзакций. Общие DTO и валидация находятся в `packages/contracts`.

Новая миграция `0006_stale_the_leader.sql` добавляет типы событий, ссылки на задачи/комментарии и сохранение упоминаний. Существующие уведомления и комментарии сохраняются. Для применения выполните `npm run db:migrate` с настроенной `DATABASE_URL_UNPOOLED`.

Список уведомлений обновляется при возвращении на вкладку, получении фокуса и раз в 30 секунд на активной вкладке. Счётчик и мигание заголовка используют общее число непрочитанных. При настройке уменьшенной анимации заголовок показывает уведомление без мигания.
